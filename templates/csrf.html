5. Cross-Site Request Forgery (CSRF)

Mode: {{ mode }}

Vulnerability: State-changing requests (transfers) accept any POST without verifying the request came from the legitimate site.

Defense: Include a unique, unpredictable CSRF token in forms and verify it on the server.

Vulnerable Code

# No CSRF token check
amount = request.form.get("amount")
conn.execute("UPDATE ...")

Secure Code

token = request.form.get("csrf_token")
if token != session.get("csrf_token"):
    message = "CSRF token invalid!"
