8. XML External Entity (XXE)

Mode: {{ mode }}

Vulnerability: The XML parser processes external entities, allowing an attacker to read local files or trigger SSRF.

Defense: Disable DTDs and external entity processing in the XML parser.

Vulnerable Code

tree = ET.parse(StringIO(xml_data))  # entities enabled by default

Secure Code

parser = ET.XMLParser()
parser.parser.entity = {}  # disable entities
tree = ET.parse(StringIO(xml_data), parser=parser)
Try: The XXE payload above reads /etc/passwd in vulnerable mode. In secure mode, external entities are disabled.
