1. SQL Injection

Mode: {{ mode }}

Vulnerability: User input is concatenated directly into SQL queries, allowing attackers to bypass authentication or extract data.

Defense: Parameterized queries (prepared statements) separate SQL logic from data.

Vulnerable Code

query = f"SELECT * FROM users WHERE username = '{username}' AND password = '{password}'"
result = conn.execute(query)

Secure Code

query = "SELECT * FROM users WHERE username = ? AND password = ?"
result = conn.execute(query, (username, password))
