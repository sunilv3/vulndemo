6. Server-Side Request Forgery (SSRF)

Mode: {{ mode }}

Vulnerability: The server fetches a URL provided by the user, allowing access to internal services (e.g., cloud metadata endpoints like http://169.254.169.254/).

Defense: Validate the URL against an allowlist of permitted hosts.

Vulnerable Code

resp = requests.get(url)  # any URL

Secure Code

parsed = urlparse(url)
hostname = parsed.hostname
allowed = any(hostname.endswith("." + h) or hostname == h
              for h in ALLOWED_SSRF_HOSTS)
if not allowed: error = "URL not allowed"
Try: http://127.0.0.1:5000/ or http://169.254.169.254/ (cloud metadata) in vulnerable mode. In secure mode, only example.com and httpbin.org are allowed.
