2b. XSS - Stored

Mode: {{ mode }}

Vulnerability: User comments are stored in the database and rendered without sanitization. Every visitor sees the injected script.

Defense: Output encoding via html.escape() when rendering stored data.

Vulnerable Code

rendered_comments = [(c["author"], c["body"]) for c in comments]
# raw data in template

Secure Code

rendered_comments = [(html.escape(c["author"]), html.escape(c["body"])) for c in comments]
Try: Inject <script>alert("Stored XSS")</script> as a comment. The script will execute for all visitors in vulnerable mode.
