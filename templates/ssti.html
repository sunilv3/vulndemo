9. Server-Side Template Injection (SSTI)

Mode: {{ mode }}

Vulnerability: User input is passed to render_template_string() with a user-controlled template, allowing arbitrary code execution.

Defense: Use a fixed template and pass user data only as template variables, with output encoding.

Vulnerable Code

template = request.form.get("template")
output = render_template_string(template)

Secure Code

safe_template = "Hello {{ name }}"
output = render_template_string(safe_template, name=html.escape(name))
