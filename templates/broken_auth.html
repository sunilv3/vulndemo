10. Broken Authentication

Mode: {{ mode }}

Vulnerability: SQL injection in login, weak password policies, and no session hardening.

Defense: Parameterized queries, strong password policy (8+ chars, uppercase, digit), session regeneration, and session expiry.

Vulnerable Code

# SQL injection in login
user = conn.execute(f"SELECT * FROM users WHERE username = '{username}' AND password = '{password}'")
# No password policy for registration

Secure Code

# Parameterized query
user = conn.execute("SELECT * FROM users WHERE username = ? AND password = ?", (username, password))
# Password policy
if len(password) < 8: error = "Password too short"

Login / Register

Try (vulnerable): Login as admin' -- with any password.
Try (secure): Register with a weak password like abc — it will be rejected.
