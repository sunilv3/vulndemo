7. Insecure Direct Object Reference (IDOR)

Mode: {{ mode }}

Vulnerability: The application exposes direct references to internal objects (user IDs) without verifying authorization.

Defense: Verify that the logged-in user owns the requested resource.

Vulnerable Code

profile_id = request.args.get("user_id")
user = conn.execute("SELECT * FROM users WHERE id = ?", (profile_id,)).fetchone()
# Renders any user's profile

Secure Code

profile_id = request.args.get("user_id")
if int(profile_id) != session["user_id"]:
    return "Unauthorized", 403
