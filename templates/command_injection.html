3. Command Injection

Mode: {{ mode }}

Vulnerability: User input is passed directly to a shell command with shell=True.

Defense: Validate input with a strict regex allowlist, and use command lists (no shell=True).

Vulnerable Code

cmd = f"ping -c 1 {host}"
output = subprocess.check_output(cmd, shell=True)

Secure Code

if not re.match(r'^[a-zA-Z0-9\.\-]+$', host):
    error = "Invalid hostname"
cmd = ["ping", "-c", "1", host]
output = subprocess.check_output(cmd)
Try: 127.0.0.1; id or 127.0.0.1 && cat /etc/passwd in vulnerable mode. In secure mode, only valid hostnames are accepted.
